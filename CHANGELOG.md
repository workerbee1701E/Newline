# Changelog

## [Unreleased]

## [0.2.0] - 2026-11-09

- Automatically refresh open documents when another program saves the file, including atomic file replacement.
- Retain the selection and reading position where possible, and preserve unsaved local edits.
- Resume automatic refresh after undoing local edits; follow the new file after Save As.
- Add automated macOS build and editor checks, a documented contribution workflow, and protected release tags.

## [0.1.0] - 2026-11-05

- Initial public source release of the native Markdown editor, including formatting, tables, footnotes, images, outline, and document statistics.
